# karaoke-captions — كابشن كاريوكي بتوقيت الكلمة

Word-level timing comes from **edge-tts WordBoundary events captured during synthesis**, so the
captions match the script exactly and need no speech recognition.

## Path A — voiceover generated by edge-tts (default)

```bash
uv run --with edge-tts python scripts/vo_karaoke.py \
  --text-file script.txt --voice ar-IQ-BasselNeural \
  --out ./scene --name scene1 --res 1080x1920
```

Run it from this skill's folder, or pass the full path to `scripts/vo_karaoke.py`.

Outputs in `--out`:
- `scene1.mp3` — the voiceover
- `scene1.words.json` — `[{text,start,end}]` in seconds
- `scene1.ass` — karaoke subtitles with the active word highlighted. Burn with
  `ffmpeg -i in.mp4 -vf "ass=scene1.ass" out.mp4` (run ffmpeg from the folder that holds the
  `.ass` file, or escape the path on Windows)
- `scene1.captions.json` — caption lines `{text,start,end,words[]}` for Remotion `<Sequence>` captions

Voices: `ar-IQ-BasselNeural` (male), `ar-IQ-RanaNeural` (female). List more with
`uv run --with edge-tts edge-tts --list-voices | grep ar-`. Optional: `--rate +8%`, `--pitch -2Hz`.

If the script stops with "truncated stream", edge-tts ended early — rerun it. A short word stream is
treated as a failure on purpose, because the mp3 may still play while most captions are missing.

## Path B — recorded voice (no edge-tts timing)

Get word timestamps with faster-whisper (CPU, `int8` is enough):

```bash
uv run --with faster-whisper python -c "
from faster_whisper import WhisperModel
import json
m = WhisperModel('small', compute_type='int8')
segs, _ = m.transcribe('vo.wav', language='ar', word_timestamps=True)
print(json.dumps([{'text': w.word.strip(), 'start': w.start, 'end': w.end}
                  for s in segs for w in s.words], ensure_ascii=False))" > vo.words.json
```

Then reuse `group_lines()` and `to_ass()` from `scripts/vo_karaoke.py` on that JSON. Speech recognition
can mishear words, so correct the text against your script before burning.

## Rules

- Caption text comes from the script, not from recognition — Path A guarantees this.
- Vertical by default (PlayResY 1920); lines stay at ≤4 words / ≤28 characters.
- Arabic font: Segoe UI is safe on Windows. For another look, install a font such as Noto Kufi Arabic
  and change the `Style:` line in `to_ass()`.

## Why the .ass looks the way it does (RTL)

libass karaoke tags (`\k`) and any inline color tag split a line into bidi runs that are laid out
left-to-right, which scrambles Arabic word order. The script therefore writes **one event per word**:
the full line each time, every word tagged, the active word gold, and for RTL lines the words in
reversed logical order — so the runs join into the correct right-to-left reading. In Remotion this trick
is not needed: the browser's bidi handles `<span>` words correctly, so use `captions.json` directly.

## Notes

- edge-tts is an unofficial client for Microsoft Edge's online read-aloud service. It needs internet,
  and the service can change or stop without notice. edge-tts is LGPLv3; this skill only calls it.
